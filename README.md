
Yonis GPT is a desktop chat app built with   Flet. It connects to an AI service running through an API on my local NAS, so you can send messages and talk to a chat bot.

## Core features

- Send a message and see the AI's answer appear as it is generated.
- Start a new conversation or open a previous one from the history list.
- Display messages with Markdown formatting.
- Show connection and request errors in the app.
